Tab System Example

Click tabs to switch between them. The server removes 'active' from all tabs, then adds it to the selected one.

Home
Profile
Settings

How it works:

When you click a button, the server returns:

<div 
    class-remove=".tab:active"
    class-add=".tab[data-tab='X']:active"
></div>

Note: This is a static example. In production, your server would return the appropriate HTML.
